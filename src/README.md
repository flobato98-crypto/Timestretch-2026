# TimeStretch 2026

A Windows desktop audio time-stretch application based on:

- Qt 6
- Signalsmith Stretch
- libsndfile
- FFmpeg

## Current status

Milestone 1:
- Qt 6 application skeleton
- CMake build
- Main window

## Build

Requirements:

- Visual Studio 2022
- Qt 6
- CMake 3.21+

Open the project with Qt Creator or CMake.
